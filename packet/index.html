PCO Print Packet

A bookmark that builds every AM and PM production report for a plan into one document you save as a single, two-sided-ready PDF. Each report is a front page and a back page, and the plan always fits its page.

← All production tools

Install (about a minute)

Works in Chrome on a computer. If you added an earlier Print Packet bookmark, delete it and add this one (you only need to do this once).

  1. Show your bookmarks bar

    Press Cmd+Shift+B on a Mac or Ctrl+Shift+B on Windows.

  2. Drag this button onto the bar

    Print PacketClick and hold the button, drag it up to your bookmarks bar, and let go.

    If the button won't drag into your bar, use one of the other ways to add it at the bottom of this page.

  3. Open a plan and click it

    Go to the plan you want in Planning Center Services, then click Print Packet in your bookmarks bar. From any other Services page it uses the next upcoming plan. You need to be signed in to Planning Center.

How To Use It

It builds the packet

A new tab opens and loads all 11 reports. This takes about 30 seconds.

Save as PDF

The print window opens by itself. Choose Save as PDF, Paper Letter, Margins Default, and uncheck Headers and footers.

File name

It's filled in for you, like Bentonville Production Packet - 2026-10-18.

What's inside

AM: Audio, GFX, Lighting, Ushers, Livestream and Production Coord. PM: Audio, GFX, Lighting, Ushers and Production Coord. Every report is exactly two pages: the plan on the front, and on the back either the stage plot (Audio, GFX, Lighting, Livestream) or the team list (Ushers, Production Coord).

Always current

The bookmark loads its latest code from this site each time you click it, and the reports are read live from Planning Center, so updates never need a re-install.

Page fit

Plans with few items get roomier spacing and long plans are tightened, so each plan fills one page. If a plan is too long to fit even at a small size, a note appears at the top of the preview.

If nothing opens

Allow pop-ups for planningcenteronline.com (icon at the right end of the address bar), then click the bookmark again.
