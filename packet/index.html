Bentonville Production Packet

One click builds all 11 production reports for a plan (AM reports + Stage Plot AM, then PM reports + Stage Plot PM) as one document you save as a single PDF.

Install (once per browser)

  1. Show your bookmarks bar: in Chrome press Cmd+Shift+B (Mac) or Ctrl+Shift+B (Windows).
  2. Drag this button up onto the bookmarks bar:

    Production Packet
  3. If dragging doesn't work: right-click the bookmarks bar, choose Add page, name it "Production Packet", and paste the code below into the URL box.

Use

  1. Open the plan you want in Planning Center Services (the Oct 18 plan, for example). If you're on any other Services page, it uses the next upcoming plan.
  2. Click Production Packet in your bookmarks bar. A new tab opens and builds the packet (about 30 seconds).
  3. The print window opens by itself. Choose Save as PDF, Paper Letter, Margins Default, and uncheck Headers and footers. Click Save.

The file name is filled in for you: "Bentonville Production Packet - 2026-10-18". If nothing opens, allow pop-ups for planningcenteronline.com (icon at the right end of the address bar) and click the bookmark again. Use Chrome, signed in to Planning Center.
