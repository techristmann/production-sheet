PCO Print Packet

A bookmark that builds every AM and PM production report for a plan, plus the Stage Plot AM and Stage Plot PM, into one document you save as a single PDF.

← All production tools

Install (about a minute)

Works in Chrome on a computer.

  1. Show your bookmarks bar

    Press Cmd+Shift+B on a Mac or Ctrl+Shift+B on Windows.

  2. Drag this button onto the bar

    Print PacketClick and hold the button, drag it up to your bookmarks bar, and let go.

    If the button won't drag into your bar, use one of the other ways to add it at the bottom of this page.

  3. Open a plan and click it

    Go to the plan you want in Planning Center Services, then click Print Packet in your bookmarks bar. From any other Services page it uses the next upcoming plan. You need to be signed in to Planning Center.

How To Use It

It builds the packet

A new tab opens and loads all 11 reports. This takes about 30 seconds.

Save as PDF

The print window opens by itself. Choose Save as PDF, Paper Letter, Margins Default, and uncheck Headers and footers.

File name

It's filled in for you, like Bentonville Production Packet - 2026-10-18.

What's inside

AM: Audio, GFX, Lighting, Ushers, Livestream and Production Coord, then Stage Plot AM. PM: Audio, GFX, Lighting, Ushers and Production Coord, then Stage Plot PM. Each report is a plan page and a teams page.

Always current

The reports are read live from Planning Center each time, so layout changes show up without re-installing.

If nothing opens

Allow pop-ups for planningcenteronline.com (icon at the right end of the address bar), then click the bookmark again.

Other ways to add it
  1. Right-click your bookmarks bar and choose Add page (or Add bookmark).
